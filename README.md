# Port Delmar: Low Tide

[![make.fun · gta6-01](https://make.fun/badge/gta6-01.svg)](https://make.fun/bounty/gta6-01?utm_source=github&utm_medium=readme&utm_campaign=gta6-01)

An original top-down open-world crime game set in a sunlit coastal city. Explore Port Delmar on foot, steal and drive cars, work for three waterfront locals, and escape police patrols. Procedural canvas art and synthesized audio run entirely from local files with no libraries.

## Run it

```sh
node serve.ts
```

Open http://localhost:8080 in desktop Chrome. No install or build step is needed.

WASD or arrows move and drive. Shift runs, E enters or exits a car, mouse aims and click fires. P or Escape pauses; M mutes. Progress saves automatically and from the pause menu. Continue restores your latest safe checkpoint.
